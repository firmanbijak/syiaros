# AI Agent Instructions and Configuration

This file provides system instructions, behavior guidelines, and project rules specifically for AI agents working on the SyiarOS repository.

## Agent Behavior Guidelines

- Focus on clean, maintainable PHP and Laravel practices.
- Ensure all business logic complies with the rules defined in `BUSINESS_RULES.md`.
- Follow domain-driven or structured coding conventions specified in `CODING_RULES.md`.
- **Do not make product decisions.** Wait for explicit user specifications.
- **Do not invent features, business rules, or documentation.** Only create, edit, organize, and maintain files based on the specifications provided. Always wait for instructions.
